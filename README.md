## About

Cyberpunk 2077 Equipment-EX Manager helps you plan builds using the expanded equipment slots added by Equipment-EX. Track slot assignments, plan cyberware and clothing combinations and document build configurations per playstyle.

---

## Features

| Feature | Description |
|---------|-------------|
| **Build Planner** | Plan equipment and cyberware slot assignments per character build |
| **Slot Tracker** | Track which Equipment-EX slots are filled per gear configuration |
| **Style Combos** | Document fashion and stat combinations for each outfit setup |
| **Build Notes** | Log build rationale and stat priorities per equipment configuration |
